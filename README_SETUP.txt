27-1 STUDY PROGRAM — GITHUB STARTER
======================================

UPLOAD THESE ITEMS TO THE ROOT OF YOUR NEW GITHUB REPOSITORY:

index.html
manifest.webmanifest
sw.js
version.json
icons/   (entire folder)

GITHUB PAGES SETUP
1. Open the repository on GitHub.
2. Upload the files above so index.html is at the repository root.
3. Commit to the main branch.
4. Open Settings > Pages.
5. Under Build and deployment:
   Source: Deploy from a branch
   Branch: main
   Folder: /(root)
6. Save.
7. Wait for GitHub Pages to publish the site.
8. Open the Pages URL GitHub gives you.
9. Start a quiz. The starter includes 3 demo questions so you can confirm the site is working.

IMPORTANT
- Do NOT upload the outer ZIP itself as the website.
- Unzip it first, then upload the CONTENTS.
- Keep the folder name exactly "icons" in lowercase.
- index.html must stay at the root of the repository.
- The demo questions are placeholders only. They are meant to prove the framework works before real 27-1 slides/questions are added.
- Future course material can be added by expanding QUESTION_BANK in index.html or by moving banks into dedicated data files later.
- User progress is browser-local and can also be exported/imported with Save Progress / Load Progress.
